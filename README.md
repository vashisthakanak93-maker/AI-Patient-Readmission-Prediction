# AI-Based Patient Readmission Prediction System

## Project Overview
This project uses Machine Learning to predict whether a patient is likely to be readmitted to the hospital.

It helps healthcare professionals identify high-risk patients and support better healthcare decisions.

## Features
- Patient Data Management
- Patient Search by Patient ID
- Machine Learning Based Prediction
- Patient Database
- User-Friendly Web Interface

## Technologies Used
- Python
- Flask
- Machine Learning
- Scikit-learn
- HTML
- CSS
- SQLite

## Project Structure
- dataset/
- model/
- static/
- templates/
- app.py
- database.py
- patient.py
- predictor.py
- train_model.py
- requirements.txt

## Installation

1. Clone the repository:
   git clone https://github.com/vashishthakanak93-maker/AI-Patient-Readmission-Prediction.git

2. Open the project folder.

3. Install dependencies:
   pip install -r requirements.txt

4. Run the application:
   python app.py

## Project Objective
The main objective is to use machine learning to help predict hospital patient readmission and assist healthcare providers in planning better patient care.
